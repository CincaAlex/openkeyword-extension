# Security policy

Please report vulnerabilities by email to contact@openkeyword.org. Do not open a public issue or
pull request for security problems.

Include what you found, the steps to reproduce it, and the extension version (shown on
`chrome://extensions`). We will confirm receipt, keep you updated while we work on a fix, and
credit you in the release notes if you want.

In scope: this extension and the code in this repository, for example anything that makes it read
more than the search words described in the README, send data the user did not opt in to, or run
code that is not part of the package.

Only the latest published version is supported.
